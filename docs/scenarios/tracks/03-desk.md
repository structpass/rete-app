# トラック 3 — Desk（チャット・タスク・昇格・器の切替）

> 記法は [`../README.md`](../README.md)。範囲: `/desk` の 2 ペイン。チャットのテーマと発話、リアクション、タスクの作成・移動・編集・顛末、分類、添付、器（組織・プロジェクト・チャネル・個人）の切替。
> 対象外: ファイルそのものの操作（→ トラック 4）、所属の付与（→ トラック 6）。

## 0. この画面群の権限

- 読み書きは**ログインしていれば通る**（業務ロール層は ADR 0077 で撤去済み）。見える範囲は**所属**で決まる。
- 編集・削除は**投稿者本人かシステムADMIN**。他人の発話・タスクは編集できない（管理者は例外）。
- 器（Space）を跨いだ ID 指定は **404**（存在ごと隠す）。403 ではない。
