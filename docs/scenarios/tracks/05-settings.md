# トラック 5 — 設定（メンバー・招待・監査・テナント・管理グループ・ログイン設定）

> 記法は [`../README.md`](../README.md)。範囲: `/settings`（メンバー）、`/settings/invites`、`/settings/audit-log`、`/settings/login-settings`、`/settings/tenant-settings`、`/settings/groups`、`/settings/memberships`、`/settings/display`、`/settings/calendar-holidays`。
> 対象外: 組織・プロジェクト・チャネルの構造そのもの（→ トラック 6）。

## 0. この画面群の権限

- 設定の画面は**システムADMIN だけ**が開ける（`@Roles(ADMIN)`）。MEMBER が直接叩くと 403。
- 例外は「所属管理」（`/settings/memberships`）で、スコープの管理者も自分の範囲を触れる。
- 監査ログは**期間を指定**して初めて書き出せる（最大 92 日）。
