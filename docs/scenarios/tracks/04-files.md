# トラック 4 — ファイル（フォルダ・版管理・タグ・検索）

> 記法は [`../README.md`](../README.md)。範囲: `/files`。フォルダの作成・移動・削除、アップロード、版の追加と版指定取得、タグ（単一・一括）、名前検索・タグ検索、アップロード設定。
> 対象外: 掲示板への添付（→ トラック 2）、発話・タスクへの添付（→ トラック 3）。

## 0. この画面群の権限

- 読み書きは**ログインしていれば通る**。見える範囲は**器（Space）の所属**で決まる。器が違えば **404**。
- ファイルは必ず器に属する。**ルート直下に作る時は器の指定が必須**、親の下に作る時は親から継承する（親と違う器を送ると 400）。
- アップロード設定の変更だけは**システムADMIN**。

### S-FILE-04-開発エージェント一覧の行をツリーのフォルダへ落として移す（自動）

S-FILE-04 の手引き「`/files` → 一覧の行を掴み、ツリーのフォルダで離す」その道を確かめる。
2026-10-27 の実測（d825）ではこの道が動かなかったため赤として残していたが、d862 で道を足した。

| 項目   | 内容                                                                                                                                                                                   |
| ------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 前提   | フォルダ A と、その中にファイル 1 件。移し先のフォルダ B                                                                                                                               |
| 手順   | 1. フォルダ A をツリーで開く<br>2. 一覧の行を掴み、ツリーのフォルダ B の上で離す<br>3. 移動の要求と、A の一覧の中身を見る<br>4. ツリーで B を開き、一覧を見る                          |
| 期待   | 2〜3. 移動の要求（`PATCH`）が 200 で返る。A の一覧からその行が消える。画面の現在地（パンくず）は A のまま<br>4. B の一覧にその行がある                                                 |
| 後始末 | 作ったファイル・A・B の順に削除                                                                                                                                                        |
| 実行   | 自動 `@S-FILE-04-開発エージェント`（`zz-files-screen.feature`・project `screen`）。手順 3 の「A の一覧からその行が消える」は、読み込み直す前の一覧そのもので確かめる（S-FILE-04-開発エージェントの 3 番目の手順） |

**動きと判定の内訳（2026-10-28・d862）**

画面は掴んだ物と落とす先の組み合わせごとに動きを分けている。これまでは三通り（ツリーのフォルダ → ツリーのフォルダ／
一覧の行 → 一覧のフォルダの行／検索結果 → ツリーのフォルダ）だけを移動として扱っていた。`一覧の行 → ツリーのフォルダ`
を四通り目として足し、検索結果から移す時と同じ規則で移す（フォルダは自身・子孫への移動を弾き、今開いているフォルダへ
戻す操作は何もしない）。

移した後も画面の現在地は移す前のフォルダのまま。ファイルは移し元の一覧から消え、移し先の一覧に出る（移動の後に
一覧を取り直す）。フォルダはツリーの位置が動くことで分かり、一覧の中では移す前と同じ行が残る。画面を移し先へ
飛ばさないのは、移動のたびに現在地が変わると、続けて別の行を移せなくなるため。
