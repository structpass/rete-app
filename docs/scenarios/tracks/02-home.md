# トラック 2 — ホーム（掲示板・FAQ・カレンダー・お気に入り）

> 記法は [`../README.md`](../README.md)。範囲: `/hub`（掲示板）、`/hub/faq`、`/hub/calendar`、横断お気に入り、ホームの編集権限。
> 対象外: チャット・タスク（→ トラック 3）、ファイルそのものの操作（→ トラック 4）。

## 0. この画面群の権限

ホームの書き込みは **管理グループのフラグ**で決まる（ADR 0077 で業務ロール層は撤去済み）。

| 操作                             | 必要なもの                                              |
| -------------------------------- | ------------------------------------------------------- |
| 掲示板の作成・編集・削除         | システムADMIN、または管理グループの「掲示板の編集」     |
| FAQ の作成・編集・削除           | システムADMIN、または管理グループの「FAQ の編集」       |
| カレンダーの予定作成・編集・削除 | システムADMIN、または管理グループの「カレンダーの編集」 |
| お知らせタグの管理               | システムADMIN、または管理グループの「タグの管理」       |
| 閲覧・お気に入り                 | ログインしていれば誰でも（お気に入りは本人のみ）        |

画面は `/hub` の「掲示板」「FAQ」「カレンダー」の 3 タブ。カレンダーの祝日は `/settings/calendar-holidays`（管理者）。
